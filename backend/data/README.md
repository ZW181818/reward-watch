# Reward Watch Local Data

`cases.json` is generated by the official-source update script:

```powershell
.\backend\.venv\Scripts\python.exe backend\scripts\update_cases.py --strict
```

When `DATABASE_URL` is configured, the FastAPI app reads the synchronized
PostgreSQL snapshot and applies published administrator overrides. If the
database is unavailable it reads `backend/data/cases.json`; if that file does
not exist it falls back to the fictional `sample_cases.json` file.

The US adapter follows the official FBI Wanted API's reported total through all
pages. One Canada adapter reads the official Ontario Provincial Police public
investigations feed and imports active rewards, Most Wanted, and ROPE Wanted
records. Another discovers the latest exact-title `Saskatchewan RCMP: Wanted
Persons` monthly release and maps real gallery images to matching profiles. The
Fugitifs Quebec adapter imports active provincial profiles, their responsible
police service, physical description, case summary, and complete image gallery.
The Edmonton Police Service adapter follows its current most-wanted index and
imports each linked profile with its official image and posting date. British
Columbia coverage reads the BC RCMP's embedded official newsroom feed and the
official WordPress JSON endpoints published by Vancouver Police and CFSEU-BC.
Those adapters import explicit wanted notices with official images and use
later official closure posts to remove identified people who were arrested,
located, returned to custody, surrendered, extradited, or reported deceased.

Four dedicated cash-reward adapters broaden coverage beyond general wanted
feeds. The U.S. Department of State adapter follows every published Rewards for
Justice API page. The U.S. Marshals adapter follows the complete Profiled
Fugitives catalog and imports profiles that state a dollar reward. The Nova
Scotia adapter follows every working detail page in the province's Rewards for
Major Unsolved Crimes directory. The U.S. Postal Inspection Service adapter
queries the official nationwide Wanted Poster directory for every listed state
and imports each unique reward notice and its complete image gallery. These
adapters require both an explicit cash amount and at least one official source
image.

Active wanted feeds exclude resolved records (`captured`, `closed`, `located`,
or `deceased`) and records without an official image or meaningful narrative.
The U.S. Marshals catalog retains profiles carrying explicit apprehended or
deceased updates but labels them `Closed`. The importer keeps the detailed
narrative, aliases, available physical description, field office, reward
statement, and source update date. `lastVerified` records when Reward Watch
successfully retrieved the record from the official source;
`sourceUpdatedDate` records the source's own modification date.

`sourceTitle` and `sourceAuthor` identify the official origin shown in the app.
`regions` contains normalized US states or Canadian provinces used by the case
browser. Empty US regions mean the source did not provide enough information to
assign a state reliably; those records remain visible under `All states`.

`source_exclusions.json` contains records that remain in the upstream API even
though their public case page or media redirects elsewhere or no longer
resolves. Each entry is browser-reviewed and should be rechecked periodically;
the update script skips it and continues scanning for usable records.

`update_status.json` records the result of each source refresh. A temporary
failure uses only that source's previous records, so one unavailable agency
cannot erase another agency's data. Pass `--strict` when a non-zero exit code is
required for any stale fallback. The default is a full sync; positive source
limit flags are intended only for development samples.

`source_cases.json` keeps one normalized record per upstream source so a later
source outage can reuse that source's last successful snapshot even when the
app-facing records have been merged. `data_quality_report.json` records counts,
currencies, multi-source merges, image coverage, freshness, and quality-gate
results for each completed update. An absent cash amount is `null`; positive
amounts include `USD` or `CAD` in `rewardCurrency`.

The GitHub Actions workflow in `.github/workflows/update-official-data.yml`
runs hourly and commits refreshed case data and source status.

The RCMP adapter is suitable for development and non-commercial use with the
included source attribution. RCMP terms require prior written permission for
commercial redistribution of site materials, and separately restrict official
symbols. Obtain that permission before a commercial production launch.
